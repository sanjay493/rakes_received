Chrome Extension

To send FOIS reports from another computer, install the extension in Chrome on that computer. You only need to do this once.

Download Extension
How to install and use it
  1. Unzip the downloaded file into a folder you'll keep. Chrome keeps loading the extension from that folder, so don't delete it.
  2. In Chrome, open chrome://extensions (type it into the address bar) and turn on Developer mode.
  3. Click Load unpacked and choose the unzipped folder.
  4. Click the puzzle-piece icon in the toolbar and pin Rakes Received Exporter.
  5. Log in to FOIS, open the report and select Show All.
  6. Click the extension icon, enter the API token (it's remembered after the first send) and click Send to dashboard. Ask your administrator for the token.

To update the extension, unzip a new download over the same folder, then click the reload icon on its card in chrome://extensions.
